# PropertyHub Frontend

React frontend for PropertyHub property search application.

## Prerequisites

- Node.js 18+
- npm or yarn

## Setup Instructions

### 1. Install dependencies

```bash
cd frontend
npm install
```

### 2. Start development server

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

## Features

- **Property Search**: Search by city, locality, listing type, budget, bedrooms
- **Responsive Design**: Works on desktop and mobile
- **Dark/Light Mode**: Toggle theme with persistence
- **Filtering**: Advanced filter panel with real-time updates
- **Pagination**: Browse through property listings

## Project Structure

```
src/
├── components/      # Reusable UI components
├── context/         # React context providers
├── pages/           # Page components
├── services/        # API service layer
└── styles/          # Global CSS and variables
```
